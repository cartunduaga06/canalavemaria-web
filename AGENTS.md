# Reglas del repositorio

- Mantener el sitio estático Jekyll compatible con GitHub Pages.
- Trabajar en ramas de funcionalidad; no hacer merge ni empujar cambios directamente a `main`.
- No añadir analítica, rastreadores, JavaScript externo, formularios conectados ni dependencias de pago.
- No inventar contenido: usar `TODO:` y documentarlo en `docs/CLONACION.md` cuando la referencia no lo confirme.
- Todo el contenido legal debe conservarse exacto cuando el titular lo proporcione.
- Validar con `python3 scripts/validate.py` antes de abrir un pull request.
